# SITL

## Contexto

Este subdirectorio está reservado para las pruebas **SITL (Software In The Loop)** del proyecto, realizadas con **Mission Planner**. A diferencia de los otros subdirectorios del repositorio (centrados en el entrenamiento e inferencia de los modelos YOLO), aquí el objetivo es validar el software de vuelo y la integración con el autopiloto en un entorno simulado, sin necesidad de volar un dron real.

Se utiliza para probar el comportamiento del software (planificación de misión, telemetría, envío/recepción de alertas, etc.) frente a un autopiloto simulado, antes de desplegarlo en un dron físico.

> Directorio en construcción: contendrá la configuración, scripts y documentación asociados a las pruebas SITL a medida que se vayan incorporando.
